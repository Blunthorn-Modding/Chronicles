# The later researcher

**Provisional content accepted,25 October:** the operator calls these books a strong start and defers further prose/lore/event revision until main mod functionality is complete. Keep the current five journals unchanged during [Core Books & Lore](CF18_BOOKS_LORE.md). Named editing and discovery are the next library capability; the new workflow is a design awaiting review, not installed in dev51.

25 October operator direction: the recipe notes become journals left by a long-dead researcher. This person discovered the ancient city; they did not belong to its original civilization or build it. They constructed the Forge and Altar through experiments after finding the city, eventually abandoned their work, and are long dead by the present campaign. Their name, exact dates, origin and manner of death remain undecided. Keep the author anonymous until the organizer chooses those details.

This is shared authorship for later lore books, not a new NPC, faction, quest sequence or compulsory reveal. The journals record incomplete firsthand observations. The writer cannot know current players or narrate events after their own departure/death. Players may find volumes in any order; entry numbers do not schedule sessions. Avoid cryptic closing slogans, recipe lists, enchantment names and narrator explanations. Describe materials, experiments and observed results so a recipe can be inferred. Do not add player corruption or a barrier preventing departure.

Five distinct ordinary written books each describe one bundled Forge recipe. Field journal I records discovery, Forge construction and a blade/echoing-fragment trial; II records amethyst and a durable pick, then early Altar construction; III records sea-green stone and armour, with the Altar clearly the researcher's own construction; IV records flint/bow testing and increasing workshop maintenance; V records feather/boots testing and departure. Each book has three short pages. This establishes the requested origin without declaring the unknown ancient city's builders or the researcher's death.

The Quiet Below owns prose, recipe/default identities and distribution. Core owns generic item components, independent rolls, configuration and chest filling. The existing `quiet_below:forge_notes` type now defaults to **Research journals**, with five independent4% single-book entries (expected0.2 books per chest, not a weighted/exclusive20% pool). Zero or several different volumes may occur in one fill. Each volume has its own components and adjustable chance. Existing configured tables/books remain intact, including old compendiums; changing defaults never silently rewrites organizer overrides. Replace that table's entries in server JSON to adopt these defaults on an older server. The disposable review fixture will use the revised table and contain all five volumes.

Core's existing Loot Tables rows use a written book's plain title, falling back to its item ID for absent/invalid titles. This only changes the existing row label, not layout or controls. No custom reading screen or new registry item is needed. Modified recipe mappings still require corresponding prose edits; existing books do not dynamically update.
