# Forge research journals

The current content is five separate **Field journal I-V** books, one recipe experiment per volume, with three short pages each. [Researcher lore and writing contract](RESEARCH_JOURNALS.md) records the operator's direction: one long-dead later explorer discovered the city, built the Forge and Altar experimentally, and eventually abandoned the work. They were not one of the city's original builders. Their name and manner of death remain undecided. The notes are firsthand experiments and observations, with no closing slogans or direct recipe/enchantment lists.

The accepted wordless Forge workstation is unchanged. These are ordinary Minecraft written books, not new registry items or custom reading screens. The Quiet Below owns the prose and bundled recipe mappings; Core supplies existing typed loot, components, configuration and refill behavior. Core's existing loot-entry rows now show plain written-book titles so organizers can distinguish volumes. No menu layout or controls changed.

## Distribution and existing servers

`quiet_below:forge_notes` is now labeled **Research journals**. Its defaults contain five independent4% entries, one copy of the corresponding volume per successful roll, with no timed refill or minimum chest recommendation. Expected yield is0.2 books per chest. This is not an exclusive20% pool: none, one or several different volumes may appear. Bind chosen chests in Chests and adjust each book's chance in Loot Tables. Components and page text remain editable in `config/chronicle/chest-loot.json`.

Existing configured types override the complete default type; neither existing books nor configured compendiums are silently rewritten. To deliberately adopt the new defaults on an older server, back up that JSON and remove only the type object whose `id` is `quiet_below:forge_notes` from its `types` array, preserving the other objects and valid JSON. Restart the server or use the existing non-active author-mode loot reload command, `/chronicle author chest reload`; Core then supplies the new registered default in memory. Saving the table in Loot Tables persists it. Existing chest bindings retain their type ID. Alternatively replace that type's entries with organizer-authored book components.

The five default Forge recipes retain their original IDs, ingredients, enchantments, group, enabled state and level/count1. Recipe configuration overrides still need corresponding prose edits; the books describe bundled experiments and never dynamically update. Finding or reading a book does not unlock a recipe, trigger an event or advance a session.
