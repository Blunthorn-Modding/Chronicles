# LC07 banquet UI design — proposal for owner review

The interactive [mockup](../../design/last-council-banquet.html) is a design proposal, not implemented or approved gameplay. It reuses the Chronicle Game setup frame, list/detail pattern and focused dialogs. The compact simulation tests contained, scrollable content and footer. Sample values and example events are fictional.

- **Game setup → Banquet** is operator-only. Edit settings requires OP, Editing and non-active play; save rechecks these conditions. The settings popup proposes an off-by-default toggle, onset of 2 active minutes and illness lasting 8 active minutes. The 1–60 minute ranges in the prototype are illustrative and await review.
- Proposed fixed policy, also awaiting review: Nausea I and Slowness I, no direct damage; illness survives death and reconnect, with its clock paused offline; antidote fully cures and doses do not stack. The implementation must preserve the existing active-play/pause semantics and the brief's non-lethality and political-rights requirements.
- **Give supplies** is a separate explicit OP action. Select an online participant and bounded quantities, review and confirm. The prototype demonstrates cancellation, a missing/offline recipient, invalid amounts and delivery failure. Its 0–16 per-item limit is illustrative, not an approved stock policy. Inventory conservation, atomicity and uncertain delivery require implementation design; the mockup does not establish those guarantees. No automatic supply or starting-gear integration is proposed.
- The **private moderation log** is a separate screen available only to the assigned Chancellor; ordinary OP status does not grant it. This example navigation exists for review and does not decide the native entry point. Public history, normal drink items, labels, tooltips and ordinary lists must not expose contamination or perpetrator. Normal and contaminated drinks look identical.
- Physical use remains the gameplay: drinks usable at full hunger, a poison dose used with a drink in the offhand, and an antidote drunk to cure. The mockup does not expose an extra player or political dashboard.

The user must review the new workflow, values, effect tuning, death/offline and cure/stacking policies, supply limits and private log before native UI implementation. The LC-07 brief remains authoritative and unchanged. The mockup is an interaction illustration, not evidence of native gameplay, inventory transactions, access enforcement or multiplayer behavior.

Lead reviewed the proposed wireframe before authoring and the completed normal/compact screenshots afterward. Local Edge checks passed on 11 November: twelve checks covering disabled initial proposal, Chancellor-only sample log, non-active editing guard, timing validation/save feedback, required recipient, gift bounds, explicit confirmation, cancellation and compact frame containment, with no JavaScript exceptions. Screenshots and reproducible browser script are retained under ignored `output/playwright/banquet-*`. The main content scrolls inside the compact frame; the footer remains contained. This verifies only the HTML prototype. Owner workflow review is still pending.
