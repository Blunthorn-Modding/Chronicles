# LC01 physical paper copy flow

Owner choice: personal information remains available in the menu, and a player may request physical copies of selected papers. Opening a menu never delivers an item automatically.

In **My house**, add a small **Copy paper…** control below the current category. It opens the existing shared picker style, scoped to that category. House information has one paper option; Secrets, Goals, and Other houses' secrets offer each current entry separately. Selecting one entry requests exactly one paper, so the player chooses what to physically share. Cancel returns without requesting a copy. A successful request uses the normal notice; a full inventory or other refusal shows the normal reason and delivers nothing.

The picker uses the player's already authorized personal projection. The server rechecks the current player, assignment, selected entry, and inventory capacity before delivery. It does not expose another player's private papers or add a catalogue/export entry. Reuse the existing PersonalScreen list and popup patterns; this is one control and a focused chooser, not a new browser. Validate compact and normal layouts and refusal/retry in native play when implemented.
