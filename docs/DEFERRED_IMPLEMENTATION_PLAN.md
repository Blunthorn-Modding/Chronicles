## Map/content boundary

The organizer explicitly confirms that map setup travels with the map, independently of the scenario mod. Regions, Points/Block sites, chest bindings, saved area states, starting/respawn placement and map settings remain world-owned. Portable exports contain reusable definitions, never player UUID assignments, inventory/discovery receipts, sessions, source/execution histories, live ecology or saved terrain payloads. This is not a map-preset exporter.

The initial UI should expose a deliberate capture/export popup near the editor controls, reusing current content editors. A cosmetic World/Scenario switch must not pretend to redirect persistence or modify an installed JAR.
