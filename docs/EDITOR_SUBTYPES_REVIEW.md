# Region and Location editor review

Use the matching dev57 pack and the authenticated review server at `127.0.0.1:25589`. Existing world/catalog data is retained. Pause play and enable Editing before authoring; enable global Building Mode when changing terrain. Start/End application still refuses occupied or unloaded target areas.

1. Under **Regions**, choose **Create region** above the list. Ordinary Regions and those with optional Saved states both use the same Debug shovel: left-click corner 1, right-click corner 2, or use the existing pos1/pos2 commands. Save with `/chronicle region save`; cancel with `/chronicle region cancel`. Reopening an existing Region for editing lends the same tool.
2. **Choose subtypes** enables Saved states on an existing Region. **Preview bounding box** immediately displays geometry. Capture Start/End independently; applying a state replaces blocks and containers. A no-op geometry save keeps both states. Changed bounds with Saved states first produce a warning without writing; confirm the reviewed proposal with `/chronicle region save confirm` (or the menu confirmation). Changed bounds require deliberate recapture, including a warning before invalidating the opposite state. Removing Saved states retains the Region and offers Start/End/unchanged.
3. Under **Locations / Block sites**, select the ship control and enable **Departure**. Its configuration stays in one popup: warnings, boarding Region and optional state of that same Region. Save/edit/cancel should retain the chosen control and exact warning text. Missing or stale state references remain unresolved until deliberately repaired. The two live departure confirmations permanently end participation, so use them only when ready to test that outcome.
4. Under **Player Roles / Starting gear**, only assigned supplies appear. **Add item** opens a separate searchable catalog. Change quantities or remove assignments, then save the whole role. Cancel and switching sections retain the parent draft appropriately.

There are no standalone Area changes or Departures tabs and no Region-side reverse assignment. Existing command aliases and durable area/departure histories remain supported. The previously reported intermittent stuck outline is still open: this reorganization is not a claim that it has been reproduced or fixed.
