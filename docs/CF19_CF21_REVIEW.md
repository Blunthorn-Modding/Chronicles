# Combined dev55 review

Use the matching dev55 client pack and the current authenticated review server, `127.0.0.1:25589`. The existing world/configuration and access list were preserved. This review covers the generic tools; the handcrafted map and final cast/content are still pending.

1. **Navigation and roles.** Open the editor. Player Roles, Departures and Area changes are separate Advanced entries. Create is above each existing list. Pause play and enable Editing to create/edit definitions. Roles support a player limit, selectable/GM-only state, starting/respawn Points, item supplies and named lore books. Assign/clear a role from the selected account under Players. Existing participants are migrated as already started: assigning yourself a role deliberately does not replay its starting kit or books. New-account first entry and respawns were exercised by the native fixture.
2. **Area changes.** Enable global Building Mode if preparing terrain while play is paused. Create a named area and select Start or End first. In the world use the private Debug shovel (left/right corners), or the existing `/chronicles author region pos1` and `pos2` commands. Save with `/chronicle area change save`. Return to Area changes, prepare the other scene inside the same bounds, then use Save current area state. Both states can be recaptured. Preview shows the private bounds; applying a reviewed state replaces blocks and container contents. Move non-spectator players outside before applying. Delete asks which state to leave, or leaves the world unchanged. The underlying Core Region remains visible in Regions.
3. **Departure setup and play.** Edit The only ship, or create another departure. Choose a Block site for its control, an existing boarding Region, and optionally an Area change plus Start/End. Bind looked-at block can create the control's ordinary Block site. During active play, turn Editing off and interact as a participating player aboard. Check the passenger list, two distinct stacked warnings, Back and Cancel before accepting.

Test final departure last: accepted passengers become permanently departed Spectators, and if no enrolled characters remain the campaign concludes. Offline characters are not taken from saved positions; an enrolled offline character left behind prevents conclusion. A linked Area applies after the passengers are safely saved as Spectators. Ordinary rejoin, role reassignment and reconnect do not undo departure. This is intentional gameplay, not a temporary teleport preview.

Evidence and untested limits are in [TEST_PLAN](TEST_PLAN.md), [CF19](CF19_IMPLEMENTATION.md), [CF20](CF20_IMPLEMENTATION.md) and [CF21](CF21_IMPLEMENTATION.md). Changing colors, prose, cast and actual map bindings remains part of later map/content work.
