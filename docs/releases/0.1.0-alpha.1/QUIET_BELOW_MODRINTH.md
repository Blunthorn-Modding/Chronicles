# The Quiet Below

A roleplay campaign about an ancient city's spreading sculk—and what people
choose to do with it.

The sculk spreads physically from a Relic Heart along connected surfaces.
Living sculk brings benefits as well as costs. Players can investigate,
coexist, cut connections, contain the growth, weaken and destroy the Heart,
or leave aboard a configured ship. There are no mandatory factions, player
corruption mechanics or prescribed events for particular sessions.

- Heart-connected ecology with configurable fixed or population-based growth.
- Visible healthy, fading and dormant sculk, sensors, catalysts and shriekers.
- Crop growth and passive healing, balanced against prolonged contact costs.
- An Ancient Forge with item-based enchanting and a mysterious Ancient Altar.
- A weakening Relic Heart, audible defence and a final growth attempt.
- Six default roles, nine lore books, nine authored Events and four loot tables.
- Bundled local Event audio, with creator and license credits included.

## Installation and map setup

Install matching **Chronicle Core** and **The Quiet Below** on the server and
every client. Requires **Minecraft Java 1.21.10**, **Fabric Loader 0.19.5+**,
**Fabric API** and **Java 21+**. Proximity roleplay works well with the optional
Simple Voice Chat mod.

No handcrafted map is bundled. Prepare your own world with Core's in-game
editor (**O** or `/chronicle`, operator permission required). Bind the city,
Heart, role destinations, chests and any ship/Region changes you want to use.
Defaults appear on a fresh map, and incomplete Events show `!` with setup
details. Once configured, map bindings and Event/flag progress stay with the
world. Reusable content/settings retain their documented mod/config storage.
