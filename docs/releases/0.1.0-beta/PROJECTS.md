# Project creation fields

Prepared for the two Minecraft Java mods on **Modrinth**, version **0.1.0-beta**. Choose **Mod** as the project type for both.

## Chronicle

- **Name:** Chronicle Core (the Chronicle framework; keep your chosen page name).
- **Owner:** Your personal Modrinth account. The author recorded in the mod is **TheOnlyAesir**; choose that account if it is your Modrinth username.
- **Visibility:** Public.
- **Summary:** Build Minecraft roleplay campaigns with in-game tools for sessions, character roles, lore, loot, locations and story events.
- **Page description:** Copy `CORE_DESCRIPTION.md`.
- **Version changelog:** Copy `CORE_CHANGELOG.md`.
- **Download:** `chronicle_core-0.1.0-beta.jar`.

## The Quiet Below

- **Name:** The Quiet Below.
- **Owner:** The same personal Modrinth account as Chronicle.
- **Visibility:** Public.
- **Summary:** A Minecraft roleplay campaign where living sculk spreads from an ancient city, offering power at a cost and leaving its fate to the players.
- **Page description:** Copy `QUIET_BELOW_DESCRIPTION.md`.
- **Version changelog:** Copy `QUIET_BELOW_CHANGELOG.md`.
- **Download:** `quiet_below-0.1.0-beta.jar`.

Both releases target **Minecraft Java 1.21.10**, **Fabric Loader 0.19.5+**, **Fabric API** and **Java 21+**, on the server and every client. The Quiet Below also requires Chronicle Core; Chronicle Core can be installed independently.

Use **0.1.0-beta** as the version number and **Beta** as the release type. Public is the intended final visibility after Modrinth review; this package does not establish a live page or moderation status.
