# The Quiet Below 0.1.0-beta

Initial public beta for Minecraft Java 1.21.10 on Fabric, using matching Chronicle Core 0.1.0-beta. This changelog describes the included features; it does not assume a previous public release.

- Heart-connected sculk growth along physical surfaces, with configurable fixed or population-based growth.
- Healthy, fading and dormant vitality states, including sculk sensors, catalysts and shriekers.
- Crop-growth and passive-healing benefits balanced against prolonged-contact costs.
- Ancient Forge item-based enchanting and Ancient Altar bargains/prayers.
- A destructible Relic Heart with weakening conditions, audible defence and a final growth attempt.
- Six default roles, nine lore books, nine authored Events and four editable loot tables.
- Default Events and flags initialized on fresh maps; map-dependent Events show **!** until configured.
- Prepared worlds retain their map bindings and saved Event/flag progress.
- Bundled local Event audio with creator, source and license credits.
- Removed the obsolete Readiness Check and Mine Whisper prototype actions. The authored Whisper from Below Event remains.

Install this mod and Chronicle Core on the server and every client. Requires Fabric Loader 0.19.5+, Fabric API and Java 21+.

No handcrafted map is bundled. City, Heart and other map bindings require operator setup. Map-specific balance, discovery placement and group/voice playtesting remain outstanding. Back up worlds and configuration before upgrading; schema migrations and configured enchantment-cap reductions can be permanent.
