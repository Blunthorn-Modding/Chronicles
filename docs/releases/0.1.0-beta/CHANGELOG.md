# Chronicle and The Quiet Below 0.1.0-beta

Two separate mod releases for Minecraft Java 1.21.10, Fabric Loader 0.19.5+, Fabric API and Java 21+.

- **Chronicle Core:** Use [CORE_CHANGELOG.md](CORE_CHANGELOG.md) for its version page.
- **The Quiet Below:** Use [QUIET_BELOW_CHANGELOG.md](QUIET_BELOW_CHANGELOG.md) for its version page.

Core is the reusable roleplay framework. The Quiet Below is a separate campaign that requires matching Core. Both mods are installed on the server and all clients when running The Quiet Below.

This beta packages the existing Chronicle release baseline. No map is bundled; map-specific balance and group/voice testing remain outstanding.
