# Chronicle Core

Build a world, give your players a place in it, and let the story develop in play.

Chronicle is a framework for Minecraft roleplay campaigns. It brings session controls, character roles, lore, locations, loot and story events together in an in-game editor, so a game master can prepare a campaign around their own world.

Use it as the foundation for your own setting or alongside a campaign mod such as **The Quiet Below**.

## Tools for your campaign

- **Sessions and Building Mode:** Start, pause, resume and end play. World simulation freezes outside active play while players can still move and chat; Building Mode supports preparation between sessions.
- **Characters and roles:** Give players public character cards and configure roles with starting equipment, lore and spawn points.
- **Regions and locations:** Mark important places, bind block sites and destinations, save alternate terrain states, and configure group departures.
- **Books and loot:** Write and distribute named lore books, track discoveries, and set up chest bindings with editable loot tables.
- **Events and flags:** Combine triggers, prerequisites and delays with messages, sounds, flag changes, encounters and saved Region changes.
- **Reusable scenarios:** Export scenario content while keeping map bindings and live campaign progress with the world.

Open the editor with **O** or **/chronicle**. Editing requires operator permission. Chronicle provides the shared tools; campaign mods supply their own setting, starting content and specialist mechanics.

## Installation

Requires **Minecraft Java 1.21.10**, **Fabric Loader 0.19.5 or later**, **Fabric API** and **Java 21 or later**. Install Chronicle Core on the server and every player's client. The Quiet Below is an optional campaign and is not required to use Core.

Simple Voice Chat is recommended for proximity roleplay. SpiffyHUD and FancyMenu are optional client integrations; Chronicle also has a native interface. Download these mods separately from their authors.

## Public beta

This beta is for server owners and game masters preparing their own campaign worlds. The main tools are implemented and have automated and native regression coverage. Testing with a real campaign group and a production map remains outstanding. **No prepared map is included.** Back up your world and configuration before upgrading.
