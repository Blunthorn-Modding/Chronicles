# M9 full-city capacity and bounded scans

21 October 2026. Continue from accepted crop/healing implementation. Reviewable features do not stop independent development; stop only when feedback or a product decision blocks further work. Existing production and review worlds remain untouched.

The historical MCA count of 83,431 supported cells across 256 chunks exceeded the original 32,768-cell limit. This slice supports the whole source rather than narrowing its bounds. Quiet Below owns all changes; Core services, layouts, assets and campaign behavior stay unchanged.

## Implementation and acceptance

1. Keep the existing 256 source reads, 128 graph/vitality checks and four mutation intents per tick. Replace five repeated full ownership snapshots with reusable stable-slot cursors. Scan creation and each slot step are constant work; holes consume budget, concurrent mutation never extends a pass indefinitely, and churn cannot grow the slot array beyond the ownership cap. Crop source discovery uses these cursors too; its independent 262,144-section and 8,192-crop bounds stay unchanged.
2. Raise the coupled ownership/frontier bounds to 131,072 / 524,288 positions only alongside measured replay/checkpoint/heap and tick evidence. Keep the strict 64 MiB/150,000-record journal, 64 KiB line and JSON-node bounds. No unbounded history, chunk force-loading, asynchronous world writes or automatic compaction. Old records remain valid; larger worlds require the new build, and rollback restores a stopped backup plus its jars.
3. Exercise dense ownership at the new bound, pruning/reuse, actual topology, checkpoint/replay and strict refusal beyond capacity. Record bytes, records, elapsed time and heap evidence. Validate original source geometry without allocating a set for every scanned interval at startup.
4. Run the full generated native city through normal loaded-only indexing with Heart-unloaded visits, whole-city convergence at20 TPS, occupied growth, natural unload stability and restart/reload. Record complete counts, journal/heap, server tick durations and ecology callback timings; test helpers may prepare normal generation, never campaign runtime force-loading. Preserve failed runs and distinguish test limits from production readiness.

Success establishes this city's capacity and a finite reproducible soak, not arbitrary map size or unlimited campaign duration. The conservative unknown-chunk hold remains; a full-city bench loads its source normally for certification. Further scalability and automatic maintenance remain separate work if measurements require them. Update backlog, decisions, review notes and exact test evidence after verification.

## Native city evidence

The native full-city and restart trial passed on 21 October 2026 (`../reports/qb08-city-scale-native-final.json`). Each run takes an exact pre-index census of the current world rather than assuming another generated world's aggregate. The passing source contained 83,691 supported cells in the complete 256-chunk bounds. It completed bounded loaded-only indexing, Heart-unloaded visits during preparation, a natural-unload stability check, and a save/restart/reload identity check. It does not use campaign runtime force-loading.

Each phase then ran 1,200 occupied ticks at 20 TPS in a disposable creative, peaceful, single-player fixture with simulation distance 3 and view distance 12. The initial sample took 61.20 seconds: owned cells 83,691 to 83,813, journal 17,590,053 to 21,450,795 bytes, peak sampled heap 860,099,512 of 2,147,483,648 bytes, native p99 25.19 ms and ecology callback p99 19.68 ms. The restart sample took 61.17 seconds: owned cells 83,813 to 83,873, journal 21,452,177 to 21,484,542 bytes, peak sampled heap 836,422,656 bytes, native p99 10.16 ms and ecology callback p99 7.40 ms. Both had zero uncertified ticks. Metrics remain with the disposable world in `../test-runs/20261021T123633359661Z/world/quiet-below/city-scale-city.json` and `city-scale-city_restart.json`.

The first native city attempts are retained rather than rewritten: attempt one asserted another world's 83,431 aggregate; attempt three treated an additive graph extension as loss of certification; attempt four revealed that normal world reads could create chunk tickets and prevent natural unload. The repair uses cached-only chunk reads for ecology and crop observation. The passing run is the counterfactual check that the Heart chunk can naturally unload after the player leaves.

This is a completed native city trial, not an indefinite production soak. The dense test's retained-heap sample is not a peak-resident proof, and the native fixture does not model ordinary multiplayer combat, hostile mobs, large view distances or prolonged campaign duration. Unknown chunks still hold work conservatively; automatic compaction remains out of scope.

Native fixture acceptance now takes an exact pre-index census of this world's positions and block types across the complete native bounding box, rather than borrowing another generated world's aggregate count. It requires equality of the census and indexed ownership, plus an actual source larger than the old cap. Save/restart records a canonical SHA256 of every current owned position, original terrain baseline, current shape, raw vitality and tuning; equal aggregate counts alone are insufficient. Native mean and p99 tick processing must both stay below50ms, with ecology callback p99 below25ms. Preparation/index acceleration is excluded from this20-TPS sample.
