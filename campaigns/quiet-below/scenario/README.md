# Quiet Below pilot scenario material

> These texts belong to the technical prototype and are not production canon. The operator's 19 October 2026 feedback calls for a coherent ancient-city/sculk campaign and a handcrafted map. Use [the revised outline](../../../docs/THE_QUIET_BELOW.md) before authoring new story content; do not carry these signs' claims about an intelligence into the campaign by default.

These are original, reusable M5 preparation texts for the separate trial site described in [`docs/PILOT_RUNBOOK.md`](../../../docs/PILOT_RUNBOOK.md). They are plain authoring material: they do not register Minecraft content, alter a world, or require a new dependency.

Read the three clues in any order. Each has a public copy and an environmental copy so that discovery never depends on one player, one item, or a combat encounter. `character-hooks.md` is a menu of public card inspiration, not a role assignment or secret-role system.

- [`clues.md`](clues.md) — three short, readable clue texts and placement/reuse notes.
- [`character-hooks.md`](character-hooks.md) — optional public-character hooks.
